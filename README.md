# KYMA homepage preview

A standalone HTML/CSS/JS prototype of the KYMA storefront homepage (kids' beach bags, Australian brand). This is a design prototype to be ported into the KYMA Shopify theme later.

## Run locally

```bash
node server.js
# then open http://localhost:8181
```

Everything lives in `index.html` (styles and scripts inline). `kyma-logo.svg` is the brand logo. Product and section photography currently uses Unsplash placeholders and will be replaced with brand imagery.

## Sections

Floating pill header (Shop + Bundles mega menus, cart drawer, contact modal), hero with animated wave, "Our products" (3-up), "Our story" (expanding panels), Bundles, footer, plus a working cart with toast and free-shipping bar.
